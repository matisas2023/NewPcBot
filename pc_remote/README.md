# PC Helper для Android — логін і пароль

PWA-панель для керування власним Windows-ПК через інтернет.
На телефоні потрібен лише Chrome та інтернет: VPN і ручний ключ доступу не потрібні.

## Перший запуск або перехід зі старої версії

У корені репозиторію зупини старий агент (Ctrl+C) та виконай:

```powershell
git pull origin main
winget install --id Cloudflare.cloudflared -e
```

Після встановлення cloudflared відкрий нове вікно PowerShell у папці проєкту:

```powershell
.\venv\Scripts\python.exe -m pc_remote --setup
.\venv\Scripts\python.exe -m pc_remote --public
```

Під час `--setup` задай логін і двічі пароль. Логін — 3–64 літери/цифри,
крапка, дефіс або підкреслення; пароль — 12–256 символів.
Пароль у консолі не відображається. Вибери окремий довгий пароль для цього застосунку.

Налаштування зберігаються локально в `.pc-remote.json`.
Файл містить хеш PBKDF2-SHA256 з випадковою сіллю (600 000 ітерацій), а не відкритий пароль.
При переході зі старої версії `--setup` видаляє старий ключ і зберігає шлях до спільної папки.
Конфігурація виключена з Git.

`--public` запускає агент і тимчасовий HTTPS-тунель Cloudflare та показує адресу
на кшталт `https://random-name.trycloudflare.com`. Відкрий саме показану адресу
на Android і введи свій логін і пароль.

**Домен і акаунт Cloudflare для тимчасової адреси не потрібні.**
Адреса змінюється після нового запуску тунелю; сервіс не гарантує безперервну роботу.
Це обмеження [Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/).
Для постійної адреси потрібний окремо налаштований іменований Cloudflare Tunnel
та власний домен. Купувати домен для перевірки цієї версії не потрібно.

У Chrome: меню → **«Додати на головний екран» → «Встановити»**.
Після зміни тимчасової адреси відкрий нову адресу; встановлений ярлик зі старою
адресою потрібно оновити або встановити заново.

## Щоденний запуск

```powershell
.\venv\Scripts\python.exe -m pc_remote --public
```

ПК і агент мають працювати весь час. Для зупинки — Ctrl+C:
це завершує і агент, і запущений ним тунель.
Після перезапуску агента старі сеанси недійсні, потрібно знову ввійти.

Якщо cloudflared не знайдено, перевідкрий PowerShell після встановлення або
встанови його з [офіційного джерела](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/).
Агент не встановлює програми самостійно.
Якщо вже є власна конфігурація cloudflared, вона може заважати Quick Tunnel;
використовуй окремий іменований тунель, не видаляй наявні налаштування навмання.

## Вхід і захист

- Вхід за логіном і паролем, до 10 спроб за хвилину загалом для всіх адрес.
- Звичайний сеанс до 12 годин; за вибором «Запам’ятати вхід» — до 30 днів: HttpOnly + SameSite=Strict cookie, Secure для HTTPS.
- Кнопка «Вийти» відкликає сеанс на сервері. Перезавантаження сторінки не вимагає нового входу.
- Перевірка джерела запиту та CSRF-захист кожної команди, включно із завантаженням файлів.
- Старі bearer-ключі й ключі в URL не приймаються.
- Системні дії, видалення й завершення процесів мають одноразове підтвердження
  на 60 секунд, прив’язане до поточного сеансу.
- Агент слухає тільки 127.0.0.1. Порти на роутері відкривати не потрібно.
- HTTPS завершується на Cloudflare; Cloudflare виступає посередником з’єднання.
  Між cloudflared і агентом HTTP використовується лише на локальному інтерфейсі.
- API, скриншоти й файли не зберігаються в офлайн-кеші, команди не повторюються автоматично.

Для зміни забутого пароля зупини агент, знову виконай `--setup` і запусти його.
Це локальний обліковий запис, не акаунт Telegram чи Windows.

## Можливості

- CPU, RAM, системний диск і час роботи; оновлення кожні 10 секунд.
- Скриншот на вимогу.
- ESC, Enter, Alt+Tab, рух курсора, клік, гучність і медіаклавіші.
- До 100 процесів за RAM і завершення з підтвердженням.
- Файли в дозволеній папці: перегляд, передавання до 20 МБ, видалення з підтвердженням.
- Блокування, сон, гібернація, вихід, перезапуск і вимкнення.

Файли: за замовчуванням `remote_files`; іншу папку можна вказати полем `files`
у конфігурації. Обирай окрему папку для обміну, а не весь диск.
Посилання за межі папки блокуються; наявні файли не перезаписуються.
Список обмежено 500 записами.

Запускай агент у звичайному інтерактивному сеансі Windows:
скриншоти й введення на заблокованому екрані/UAC можуть бути недоступні.
Це PWA, не APK і не потоковий віддалений робочий стіл.
Повністю вимкнений ПК не вмикається без окремо налаштованого Wake-on-LAN.
Автозапуск і значок у треї налаштовуються командами нижче.
Telegram-бот працює незалежно через `python -m bot.main`.

## Локальна перевірка та постійна адреса

Без публічного тунелю:

```powershell
.\venv\Scripts\python.exe -m pc_remote
```

Відкрий http://127.0.0.1:8765 на самому ПК.
Цей локальний HTTP-режим не призначений для прямої публікації в інтернеті.

Для власного окремо налаштованого HTTPS-тунелю:

```powershell
.\venv\Scripts\python.exe -m pc_remote --origin https://pc.example.com
```

Проксі має передавати `Host: pc-helper.internal` (або початковий публічний Host)
і `X-Forwarded-Proto: https`. Для Cloudflare Tunnel вкажи
`httpHostHeader: pc-helper.internal`. Публічний Origin має точно відповідати `--origin`.

## Перевірки

```powershell
.\venv\Scripts\python.exe -m unittest discover -s tests -p test_mobile_agent.py -v
```

Тести використовують підмінний backend: не керують реальним ПК і не створюють
публічний тунель. Окремо перевіряються пароль, cookie, вихід, CSRF, обмеження
спроб входу, прив’язка підтверджень і міграція старої конфігурації.


## Трей та автозапуск Windows

Після встановлення залежностей зупини окремі ручні запуски Telegram-бота та агента.
Потім виконай у корені проєкту:

```powershell
.\venv\Scripts\python.exe -m pc_remote.desktop --install-startup --public
.\venv\Scripts\pythonw.exe -m pc_remote.desktop --public
```

Це додає лише запис PC Helper до HKCU Run поточного користувача: адміністратор
не потрібний. Запуск відбувається після входу в Windows, не до входу користувача.
Контролер у треї запускає вебагент і Telegram-бота, повторно запускає їх після
аварійного виходу та обмежує журнали ротацією. Повторний екземпляр контролера
блокується. Пункт «Стан підключення» показує окремо процеси та стан тунелю.
Пункти «Зупинити/Запустити/Перезапустити служби» керують тільки дочірніми
процесами контролера, не іншими програмами ПК. Кнопка «Вийти» зупиняє служби
та трей, але зберігає налаштування автозапуску.

Вимкнути автозапуск:

```powershell
.\venv\Scripts\python.exe -m pc_remote.desktop --remove-startup
```

Без --public працює лише локальний режим. Для налаштованого власного тунелю
використовуй --origin https://pc.example.com замість --public. Тимчасова адреса
Cloudflare все одно змінюється після створення нового тунелю; постійний домен
не створюється автоматично. При недоступному API Cloudflare агент залишається
доступним локально, а підключення тунелю повторюється з паузою 5–120 секунд.
Команди ПК при цьому не повторюються й не ставляться в чергу.

## Навігація, миша та файли

У Telegram кнопки «Назад», «Скасувати» й команда /cancel скидають незавершене
введення та повертають меню. Вибір іншого пункту меню виходить із режиму запису
медіа, пошуку чи введення шляху. «Скасувати» також зупиняє відкладену системну
дію. Підтвердження системних дій і файлів більше не перехоплюються загальними
обробниками вибору дії. Перезапуск бота не очищує чергу Telegram.

У вебпанелі є кнопка повернення й підтримка історії браузера, сенсорна панель
для руху курсора, правий/подвійний клік і прокручування. Під час втрати мережі
накопичені рухи відкидаються. Файли можна шукати в поточній папці та сортувати
за назвою або розміром, переходити шляхом через крихти навігації. Передавання
показує прогрес; після скасування онови список, бо повністю переданий файл уже
міг зберегтися на ПК.

Видалення в Telegram і вебпанелі використовує кошик Windows через Send2Trash.
Якщо кошик недоступний (наприклад, деякі мережеві диски), дія повертає помилку,
не переходячи до безповоротного видалення. Відновлення виконується через кошик
на ПК. Журнали й стан контролера зберігаються в .pc-helper-runtime (виключено з Git).

### Вхід без консолі

Запусти `PC Helper.cmd`. У треї обери «Логін і пароль», щоб задати або змінити
дані у вікні; після збереження служби перезапустяться. Для першого запуску
без готового облікового запису вікно відкриється автоматично.
«Підключити телефон (QR)» показує лише готову HTTPS-адресу, без пароля чи ключів.
Якщо тунель недоступний, вікно пояснить стан та чекатиме підключення.
Збережені сеанси переживають перезапуск агента на тій самій адресі. Зміна
пароля або «Вийти» скасовують відповідні сеанси. На новій тимчасовій адресі
потрібен повторний вхід. Пароль у браузерному сховищі застосунок не записує.

### Прямий доступ з білою IPv4

1. Завантаж офіційний Caddy для Windows з https://caddyserver.com/download
   та розмісти `caddy.exe` у `.pc-helper-runtime/caddy/`.
2. Налаштуй адресу командою `python -m pc_remote.direct --public-ip БІЛА_IP --lan-ip IP_ЦЬОГО_ПК`.
   Вона створить локальний конфіг і покаже адресу `https://pc-helper.БІЛА_IP.sslip.io`.
   sslip.io надає DNS-ім’я на основі IP без реєстрації; домен купувати не потрібно.
3. Закріпи LAN-адресу ПК у DHCP роутера та перенаправ TCP 80 і 443 на цю адресу.
   Для налаштованого під час діагностики UPnP-роутера агент перевіряє й відновлює
   відсутні перенаправлення кожні 5 хвилин; чужі правила не замінює.
4. Запусти `pc_remote/enable_https_firewall.ps1` у PowerShell від адміністратора.
   Він дозволяє лише програмі Caddy TCP 80/443 на зазначеній LAN-адресі.
5. Запусти `pythonw -m pc_remote.desktop --direct`.
   Автозапуск: `python -m pc_remote.desktop --install-startup --direct`.

Caddy отримує й оновлює публічний сертифікат автоматично. Порт 80 обслуговує
перевірку сертифіката та перенаправлення на HTTPS. Агент лишається на
`127.0.0.1:8765`; цей порт на роутері не відкривай. Вхід — за наявним логіном і
паролем, із CSRF-захистом та HttpOnly Secure cookie. QR-код з’являється після
успішної перевірки сертифіката. Адреса зберігається, поки не зміниться біла IP.
Прямий режим не запускає Cloudflare. `PC Helper.cmd` обирає його автоматично,
якщо існує локальний `.pc-helper-runtime/direct.json`.
Налаштування мережі, сертифікати й ключі зберігаються поза Git у `.pc-helper-runtime`.

### Камера, екран і записи

У вебпанелі відкрий **Камера й запис**, обери джерело й натисни **Трансляція**.
Камера й екран передаються як H.264 HLS-відео до 15 кадрів/с через чинний HTTPS.
Буферизація зазвичай дає затримку кілька секунд; вона залежить від мережі й браузера.
Перегляд вимикається при зміні розділу, приховуванні сторінки, виході або втраті мережі.
Він не вмикається автоматично після повернення. Камеру телефона застосунок не використовує.

Записи камери й екрана зберігаються як H.264 MP4, мікрофона — MP3.
Можна обрати камеру, мікрофон для відео (типово звук вимкнено), тривалість до
120 секунд та достроково зупинити запис. Закриття сторінки не скасовує вже
розпочатий запис: він завершується таймером. Максимум 25 МБ на файл і 500 МБ
на сховище; список дозволяє відтворювати, завантажувати й видаляти до кошика.
API записів потребує входу, а початок, зупинка й видалення — CSRF-токена.
Браузерний service worker не кешує кадри або відео.

У Telegram: **Медіа → Запис екрана / Запис камери**, обери камеру (для камери)
та введи 1–120 секунд. Бот чекає готовності й надсилає відео; кнопка
**Зупинити та зберегти** завершує його раніше. Також доступні окремі кадри
камери й екрана та запис мікрофона. Telegram-записи відокремлені за користувачем.
Одне джерело може бути зайняте одним записом; другий запит отримає пояснення.

Залежності FFmpeg і OpenCV встановлюються через `requirements.txt`; пошук
`ffmpeg.exe` у PATH не потрібний. Камера захоплюється через OpenCV DirectShow,
екран — FFmpeg gdigrab. Windows має дозволяти камеру/мікрофон для класичних
програм; інша програма може займати пристрій. Усі записи та службові журнали
лишаються локально в `.pc-helper-runtime/media/` і виключені з Git.

### Повний екран і запис під час трансляції

Кнопка **⛶ На весь екран** розгортає трансляцію; кнопки запису, знімка та
збереження запису лишаються у плеєрі. Там, де браузер не дозволяє системний
Fullscreen API, застосунок розгортає плеєр на всю область вкладки. Системні
панелі ОС у такому режимі можуть лишатися видимими. Підтримуються сучасні
Chrome, Edge, Firefox і Safari; Safari використовує вбудований HLS-плеєр,
інші сумісні браузери — локально включений hls.js (без зовнішнього CDN).

**📸 Знімок** відкриває кадр камери або екрана на весь екран вкладки з кнопкою
завантаження. Скриншот у розділі «Огляд» теж відкривається на весь екран
натисканням на зображення або окрему кнопку. Для готових відеозаписів також
додана кнопка повного екрана.

**● Записати** починає запис поточного відеопотоку, а **⏹ Зберегти запис**
завершує його, не перериваючи трансляцію. Без активного перегляду кнопка
запису спочатку запускає трансляцію. Запис зберігається в тому самому списку
«Мої записи». Чинні обмеження тривалості/розміру лишаються. Трансляція без
звуку; вибраний мікрофон додається лише до запису.

Вкладки одного джерела використовують спільний енкодер. До 8 одночасних
переглядів; кожен потребує авторизованого сеансу та підтвердження активності
кожні 10 секунд. Після 35 секунд без підтвердження покинутий перегляд
прибирається. Кожен HLS-фрагмент перевіряє сеанс, URL не містить пароля або
ключа входу. Початок/зупинка трансляції та підтвердження активності захищені
CSRF. Нові порти на роутері або Windows відкривати не потрібно.
Тимчасові HLS-фрагменти зберігаються в `.pc-helper-runtime/live` та видаляються
після завершення потоку. Уже розпочатий запис утримує джерело до своєї
зупинки або таймера, навіть якщо вкладку закрито.
