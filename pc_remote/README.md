# PC Helper для Android

Мобільний PWA-застосунок і агент на Windows. Працює паралельно з Telegram-ботом;
токен Telegram не потрібний. Тем і керування Navidrome немає.

## Можливості першої версії

- CPU, RAM, системний диск і час роботи ПК; оновлення кожні 10 секунд.
- Скриншот на вимогу (не потокове відео).
- ESC, Enter, Alt+Tab, переміщення курсора, клік і медіаклавіші.
- Перелік процесів за RAM і завершення обраного процесу з підтвердженням.
- Перегляд дозволеної папки, передавання файлів до 20 МБ і видалення з підтвердженням.
- Блокування, сон, гібернація, вихід із сеансу, перезапуск і вимкнення.

Системні дії, видалення та завершення процесів мають одноразове підтвердження
на сервері (60 секунд). Для процесів перевіряється час створення, для файлів —
чи не змінилися вони після підтвердження. Ключ ніколи не передається в URL.

## 1. Запуск на Windows

У корені репозиторію в PowerShell:

```powershell
git pull origin main
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe -m pc_remote --setup
.\venv\Scripts\python.exe -m pc_remote
```

`--setup` виконується один раз. Він створює `.pc-remote.json` із випадковим
ключем доступу та папку `remote_files`. Скопіюй показаний ключ на телефон.
Конфігурація й спільні файли виключені з Git. Не публікуй ключ або конфігурацію.
Для перегляду власного ключа відкрий локальний `.pc-remote.json`.
Щоб змінити ключ, зупини агент і заміни `token` випадковим рядком довжиною
щонайменше 32 символи; старі вкладки потрібно буде авторизувати повторно.

Для іншої папки зміни `files` у `.pc-remote.json` на абсолютний шлях і
перезапусти агент. Панель має повний доступ до файлів у цій папці;
обирай папку для обміну, а не корінь диска. Посилання за її межі блокуються.
Наявні файли при завантаженні не перезаписуються. Списки обмежені 500 записами.

Агент за замовчуванням слухає **лише `127.0.0.1:8765`**. Для перевірки на ПК
відкрий `http://127.0.0.1:8765`. Не змінюй прив’язку на `0.0.0.0`.

Запускай агент у своєму звичайному інтерактивному сеансі Windows, а не як
системну службу. Захоплення екрана й введення можуть не працювати на екрані
блокування або UAC; агент у такому разі повідомляє про помилку.

## 2. Доступ через інтернет із Tailscale

1. Встанови [Tailscale для Windows](https://tailscale.com/download/windows) на ПК
   і [Tailscale для Android](https://tailscale.com/download/android) на телефон.
2. Увійди в одну особисту мережу Tailscale на обох пристроях і ввімкни VPN на телефоні.
3. Поки агент працює, в іншому вікні PowerShell виконай:

   ```powershell
   tailscale serve --bg http://127.0.0.1:8765
   tailscale serve status
   ```

4. Якщо Tailscale запропонує ввімкнути HTTPS, відкрий посилання з його консолі
   та виконай налаштування. Команда покаже адресу на кшталт
   `https://your-pc.your-tailnet.ts.net` — використовуй саме свою адресу.
5. Відкрий цю HTTPS-адресу в Chrome на Android і введи ключ агента.
6. У меню Chrome натисни **«Додати на головний екран» → «Встановити»**.

Доступ залишається всередині мережі Tailscale, без відкритих портів роутера.
Не використовуй Tailscale Funnel для цієї панелі. Мережеві дозволи Tailscale
мають надавати доступ лише твоїм довіреним пристроям.

## Робота та обмеження

- Це PWA для Android, не APK. HTTPS потрібний для встановлення та service worker.
- Комп’ютер, агент і Tailscale мають бути увімкнені. Після перезавантаження
  потрібно знову запустити агент. Автозапуск у цій версії не налаштовується.
- Повністю вимкнений ПК панель не вмикає; Wake-on-LAN потребує окремого налаштування.
- Ключ зберігається в `sessionStorage` поточної вкладки/вікна. Кнопка «Вийти» очищує його.
- Офлайн зберігається лише оболонка застосунку. API, скриншоти й файли не кешуються;
  команди не ставляться в чергу та не повторюються після відновлення мережі.
- Для передавання великих файлів або повноцінного віддаленого відеоробочого столу
  потрібна інша реалізація; тут передбачено ручні знімки й крокові рухи курсора.
- Зупинка агента: `Ctrl+C`. Зупинка публікації в Tailscale: `tailscale serve reset`.

## Перевірки

```powershell
.\venv\Scripts\python.exe -m unittest discover -s tests -p test_mobile_agent.py -v
```

HTTP-тести використовують підмінний backend: вони не роблять скриншотів,
не завершують процесів і не вимикають реальний ПК.
